# 정보 구조 설계 원칙

## 설계 순서

1. 페이지 범위를 자르세요.
2. 독자 가치와 결과를 먼저 배치하세요.
3. 제목과 개요를 정리하세요.
4. 섹션 순서를 예측 가능하게 만드세요.
5. 필요한 배경 설명을 보강하세요.

## 1. 한 페이지에서 하나만 다루기

- 한 문서는 하나의 구체적인 질문이나 작업에 답하게 만드세요.
- 주제가 넓어지면 개요 페이지를 두고 세부 페이지로 나누세요.
- 제목 깊이가 `####` 이상으로 내려간다면 범위를 줄이거나 문서를 분리하는 쪽이 더 낫습니다.
- 넓은 개념을 다룰 때도 각 페이지는 가능한 한 구체적인 하위 주제를 맡게 하세요.

## 2. 가치를 먼저 제공하기

- 배경 설명보다 독자가 얻는 결과를 먼저 보여주세요.
- 기능 소개보다 독자 관점의 효용을 먼저 설명하세요.
- 실무형 문서는 보통 `무엇을 할 수 있는가` 다음에 `어떻게 하는가`, 마지막에 `배경과 세부 사항` 순서가 읽기 쉽습니다.
- 독자가 당장 행동할 수 있는 정보는 앞쪽에, 부가 정보와 예외 사항은 뒤쪽에 배치하세요.

## 3. 효과적인 제목 쓰기

- 제목마다 핵심 키워드를 넣으세요.
- 같은 수준의 제목은 같은 문법과 패턴을 유지하세요.
- 가능하면 30자 이내로 짧게 쓰세요.
- 질문형이나 감탄형보다 평서문을 우선하세요.
- 제목만 훑어도 문서 전체 흐름을 이해할 수 있어야 합니다.

## 4. 개요 빠뜨리지 않기

- 문서 시작 부분에 짧은 개요를 두세요.
- 개요에는 이 문서가 무엇을 다루고, 독자가 무엇을 얻는지가 들어가야 합니다.
- 기술적 배경을 길게 설명하기 전에 문서의 핵심 약속을 먼저 보여주세요.
- 긴 문서라면 개요 아래에 큰 흐름이나 섹션 구조를 덧붙이세요.

## 5. 예측 가능하게 하기

- 비슷한 성격의 섹션은 같은 순서와 포맷으로 정리하세요.
- 용어, 표기, 코드 블록 형식, 제목 패턴을 통일하세요.
- 독자가 다음에 어떤 정보가 나올지 짐작할 수 있게 논리적인 순서를 유지하세요.
- 설명이 필요한 섹션에서는 코드보다 설명을 먼저 배치하세요.
- 여러 항목을 비교할 때는 모든 항목에 같은 비교 축을 적용하세요.

## 6. 자세히 설명하기

- 새로운 개념이나 익숙하지 않은 전제는 먼저 정의한 뒤 사용하세요.
- 기능이 어떻게 동작하는지 독자가 이해할 만큼 설명하세요.
- 짧게 설명해서 오해가 생길 수 있다면 예시나 맥락을 보강하세요.
- 단, 배경 설명이 본문 목표를 가리지 않도록 핵심 흐름 뒤에 배치하세요.

## 7. 여러 페이지 문서 구조 설계하기

- 여러 문서로 나뉘는 주제라면 먼저 왼쪽 내비게이션을 짠다고 생각하고 계층 구조를 설계하세요.
- 전체 개요 페이지를 두고, 그 아래에 `학습`, `문제 해결`, `설명`, `참조` 문서를 배치하는 방식이 기본형입니다.
- 모든 유형을 반드시 다 넣을 필요는 없습니다. 주제와 독자 목표에 맞는 유형만 고르세요.
- 큰 주제에서는 `시작하기`, `가이드`, `설명`, `참조`, `트러블슈팅`, `용어 사전`이 자연스러운 기본 틀이 됩니다.

예시:

```text
docs/
├── get-started.md
├── tutorials/
├── how-tos/
├── explanations/
├── reference/
├── troubleshooting.md
└── glossary.md
```

## 8. 크로스링크 설계하기

- 튜토리얼에서 자세한 배경 설명이 필요하면 설명 문서로 연결하세요.
- 가이드에서 옵션 세부값이 필요하면 참조 문서로 연결하세요.
- 개념 문서에서 실제 적용 절차가 필요하면 How-to 문서로 연결하세요.
- 한 페이지에서 모든 정보를 끝내려 하지 말고, 관련 문서를 자연스럽게 오갈 수 있게 링크를 배치하세요.
- 단일 블로그 글에서도 `관련 글`, `함께 읽기`, `다음 단계` 섹션으로 같은 원칙을 적용할 수 있습니다.

## 최종 구조 점검 체크리스트

- 제목만 읽어도 흐름이 보이나요?
- 개요만 읽어도 독자가 얻는 가치가 분명한가요?
- 독자가 가장 먼저 필요로 하는 정보가 앞에 있나요?
- 섹션 순서가 독자 관점에서 자연스러운가요?
- 배경 설명이 부족하거나 과도하지 않나요?
